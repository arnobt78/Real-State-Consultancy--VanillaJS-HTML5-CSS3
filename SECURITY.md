# Security

This site is a static brochure. It has no accounts, no server, and no secret keys.

---

## Reporting a vulnerability

Please report a security problem in private. Do not open a public GitHub issue for it.

Email [contact@arnobmahmud.com](mailto:contact@arnobmahmud.com) with:

- the page or file involved
- what you observed
- the steps that show the problem

Please give the project time to look at the report before you publish the details.
